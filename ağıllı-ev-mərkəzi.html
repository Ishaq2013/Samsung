Ağıllı Ev Mərkəzi

Samsung-un SmartThings ağıllı ev mərkəzləri (Smart Home Hub) portfeli erkən Ethernet stasionar qovşaqlarından, simsiz Wi-Fi mesh routerlərdən, televizor və monitorlara inteqrasiya olunan ekran mərkəzlərindən, məişət texnikasının Family Hub sistemlərindən tutmuş Matter və Thread dəstəkli süni intellekt ev beyinlərinə qədər inqilabi bir inkişaf yolu keçmişdir.

🏠 1. Standart SmartThings Hub Stasionar Seriyası (2013–2020)

  • 🏠 SmartThings Hub v1 (2013): Ethernet kabeli vasitəsilə internetə qoşulan və ilk Zigbee/Z-Wave cihazlarını birləşdirən erkən ev mərkəzi.
  • 🏠 SmartThings Hub v2 (2015): Batareya ehtiyatı (battery backup), yerli əmrləri yerinə yetirmə prosessoru olan flaqman qovşaq.
  • 🏠 SmartThings Hub v3 (2018): Wi-Fi şəbəkəsinə qoşula bilən, daha yığcam korpuslu və sadələşdirilmiş quraşdırma sistemli mərkəz.
  • 🏠 Samsung Connect Home (2017): Yüksək sürətli Wi-Fi router və SmartThings hub funksiyasını eyni korpusda birləşdirən ilk hibrid cihaz.
  • 🏠 SmartThings Link for NVIDIA Shield (2017): NVIDIA Shield TV oyun konsolunu tamhüquqlu ağıllı ev mərkəzinə çevirən USB dongle modulu.
  • 🏠 SmartThings ADT Security Hub (2017): Təhlükəsizlik siqnalizasiyası və SmartThings mərkəzini birləşdirən toxunulabilən ekranlı qovşaq.

🔌 2. SmartThings Station Və Kompakt Dongle Seriyası (2020–2026)

  • 🔌 SmartThings Station (2023): Telefonu simsiz şarj edən və üzərindəki fiziki düymə ilə əvvəlcədən təyin olunmuş səhnələri (Scenes) işə salan kompakt mərkəz.
  • 🔌 SmartThings Zigbee/Z-Wave USB Dongle (2020): Samsung televizorlarına və kompüterlərə birbaşa qoşulan xarici qovşaq modulu.
  • 🔌 SmartThings Hub Dongle for Samsung TV (2021): Yeni nəsil QLED televizorları daxili hub xidməti ilə təmin edən aparat modulu.
  • 🔌 SmartThings Nano Hub Chip (2024): Gələcək nəsil məişət texnikasının ana platanına birbaşa inteqrasiya olunan mikro-hub çipi.
  • 🔌 SmartThings Pocket Hub Companion (2025): Səyahət zamanı otel otağındakı cihazları idarə etmək üçün portativ mini qovşaq.
  • 🚀 SmartThings Universal Zigbee/Matter Dongle Pro (2026): Bütün növ simsiz rabitə protokollarını dəstəkləyən universal USB mərkəz.

📺 3. TV Və Smart Monitor Daxili Hub Seriyası (2018–2026)

  • 📺 Samsung QLED TV SmartThings Hub (2018): Televizor ekranı üzərindən evdəki işıqları və kameraları idarə etməyə imkan verən ilk TV mərkəzi.
  • 📺 Samsung Smart Monitor M7/M8 Hub (2020): Kompütersiz işləyən və SmartThings ev cihazlarını birbaşa idarə edən monitor qovşağı.
  • 📺 Samsung Neo QLED AI Hub (2022): Matter və Thread rabitə protokollarını birbaşa dəstəkləyən flaqman televiziya mərkəzi.
  • 📺 Samsung Micro LED Smart Hub (2023): Nəhəng ekranlı flaqman televizorların əsas idarəetmə və ev avtomatlaşdırma sistemi.
  • 📺 Samsung The Frame Art Hub (2022): Rəsm əsərləri göstərməklə yanaşı divar arxasındakı ağıllı cihazları idarə edən dekorativ TV mərkəzi.
  • 🚀 Samsung AI TV SmartThings Dashboard (2024–2026): Süni intellektlə ev enerjisini və cihazların vəziyyətini izləyən son nəsil ekran mərkəzi.

🧊 4. Məişət Texnikası (Family Hub Soyuducu) Mərkəzləri (2016–2026)

  • 🧊 Samsung Family Hub Refrigerator Hub 1st Gen (2016): Soyuducunun qapısındakı planşet ekranı ilə ev cihazlarını idarə edən ilk məişət mərkəzi.
  • 🧊 Samsung Family Hub 2.0 Refrigerator (2018): Bixby səsli köməkçi və SmartThings tətbiqi inteqrasiya olunmuş mətbəx qovşağı.
  • 🧊 Samsung Bespoke Family Hub 3-Door (2022): Böyük toxunulabilən ekranı ilə bütün ev kameralarını göstərən və qapıları idarə edən soyuducu mərkəzi.
  • 🧊 Samsung Bespoke AI Laundry Hub Panel (2023): Paltaryuyan qülləsinin idarə panelindən evdəki digər cihazları nəzarətdə saxlayan sistem.
  • 🧊 Samsung Bespoke AI Family Hub 32" (2024): Nəhəng 32 düymlük ekranı ilə bütün ağıllı ev cihazlarını birləşdirən flaqman mətbəx mərkəzi.
  • 🚀 Samsung AI Vision Family Hub Ultra (2025–2026): Evin ekologiyasını, istiliyini və enerji sərfiyyatını avtomatik tənzimləyən son nəsil məişət mərkəzi.

🌐 5. SmartThings Wi-Fi Mesh Router Və Şəbəkə Mərkəzləri (2018–2026)

  • 🌐 Samsung SmartThings Wifi Mesh Router (2018): Evin hər küncünə yüksək sürətli internet verən və daxilində SmartThings Hub olan router.
  • 🌐 Samsung SmartThings Wifi 3-Pack System (2019): Böyük evlər üçün genişləndirilə bilən mesh rabitə və mərkəzi idarəetmə dəsti.
  • 🌐 Samsung AI Mesh Router Pro (2021): Wi-Fi 6 dəstəkli və ağıllı ev cihazlarının internet trafikini prioritetləşdirən mərkəz.
  • 🌐 Samsung SmartThings Wi-Fi 6E Hub (2022): Daha geniş tezlik diapazonu və aşağı ləngiməli ağıllı ev şəbəkə qovşağı.
  • 🌐 Samsung SmartThings Wi-Fi 7 Gateway (2024): Wi-Fi 7 texnologiyalı, ultra-sürətli və Matter/Thread dəstəkli şəbəkə mərkəzi.
  • 🚀 Samsung Next-Gen AI Mesh Hub (2025–2026): Süni intellektlə kiber təhlükəsizliyi təmin edən və ev cihazlarını qoruyan son nəsil router.

🧠 6. Matter, Thread Və Gələcək Nəsil AI Ev Beyni (2023–2026)

  • 🧠 SmartThings Matter-Certified Hub (2023): Müxtəlif brendlərin ağıllı cihazlarını vahid standartda birləşdirən Matter mərkəzi.
  • 🧠 SmartThings Thread Border Router (2023): Cihazlararası birbaşa, gecikməsiz və etibarlı əlaqə yaradan Thread dəstəkli qovşaq.
  • 🧠 SmartThings AI Energy Hub (2024): Evin elektrik sərfiyyatını süni intellektlə analiz edib optimallaşdıran mərkəzi sistem.
  • 🧠 SmartThings Spatial Aware Hub (2025): Evdəki insanların yerini UWB (Ultra Wideband) sensorları ilə izləyən ağıllı mərkəz.
  • 🚀 Samsung Quantum-Secure Smart Hub (2025–2026): Kvant şifrələmə texnologiyası ilə xarici hücumlardan tam qorunan gələcək nəsil ev mərkəzi.
  • 🚀 Samsung Autonomous AI Home Brain (2026): Evin bütün ehtiyaclarını insansız idarə edən tam avtonom süni intellekt ev beyini.
